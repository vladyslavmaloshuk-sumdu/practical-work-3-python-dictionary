Опис проєкту
Програма працює зі словником автомобілів.
Для кожного автомобіля зберігається:
потужність двигуна в кінських силах;
вартість автомобіля в доларах.
Програма дозволяє виконувати основні операції зі словником та здійснювати обробку його даних.

Основний функціонал
виведення списку всіх автомобілів;
додавання нового автомобіля;
видалення автомобіля;
виведення автомобілів у відсортованому порядку;
визначення загальної вартості автомобілів із потужністю двигуна понад 100 к.с.

Проєкт розробляється спільно за допомогою Git та GitHub.

Кожен учасник виконує свою частину роботи у власній гілці.
