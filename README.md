Для кожного автомобіля зберігається така інформація:

## 👨‍💻 Командна розробка

Проєкт розробляється спільно з використанням **Git** та **GitHub**.

Основна гілка проєкту:

```text
main
```

Кожен учасник виконує свою частину роботи у власній гілці.

### Робочий процес

1. Отримати призначене завдання через **GitHub Issues**.
2. Створити окрему гілку від `main`.
3. Реалізувати необхідні зміни.
4. Перевірити роботу програми.
5. Створити `commit`.
6. Виконати `push` своєї гілки на GitHub.
7. Створити **Pull Request** до `main`.
8. Дочекатися перевірки тімліда.
9. За необхідності внести виправлення.
10. Після схвалення виконати **Merge** до `main`.

Такий підхід дозволяє кожному учаснику працювати незалежно та контролювати внесені зміни.
